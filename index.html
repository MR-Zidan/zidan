Real-Time Video Analytics for Measuring Road User Satisfaction

Paper Title: “Using Video Data Analytics to Measure Road User Satisfaction Supplementing Traditional Survey-Based Approach”

Traditional road user satisfaction surveys rely only on questionnaires, which can miss real-time traffic dynamics. In this research, we built a computer-vision pipeline using YOLOv8 / RF-DETR, ByteTrack, and OpenCV to automatically track vehicles, speeds, headways, and congestion patterns from video feeds—combining them with survey analytics to measure how satisfied road users actually are.
